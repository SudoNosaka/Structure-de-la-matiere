📖 Introduction : Du Modèle de Bohr aux Atomes Réels

Nous avons vu que l'électron est décrit par 4 nombres quantiques : n, l, m, ms. Maintenant, comment répartir les électrons dans un atome polyélectronique ?

On ne se contente plus d'écrire les configurations par couche (K² L⁸ M²...). On indique le nombre d'électrons dans chaque sous-couche avec le formalisme :

(sc₁)n₁ (sc₂)n₂ (sc₃)n₃ ...

Où sci = nom de la sous-couche (ex: 1s, 2p...) et ni = nombre d'électrons.

Ce remplissage obéit à 3 règles fondamentales : Pauli, Klechkowski, Hund.

1. Principe d'Exclusion de Pauli

1.1 L'Énoncé

Dans un atome, 2 électrons ne peuvent pas avoir le même jeu de 4 nombres quantiques (n, l, m, ms).

Autre formulation : dans un système à plusieurs électrons, 2 électrons ne peuvent pas être décrits par la même spin-orbitale.

1.4 Représentation par Cases Quantiques

Une orbitale est représentée par une case :

  • Case vide : □
  • Électron célibataire (non apparié) : ↑
  • Doublet (électrons appariés, spins opposés) : ↑↓

⚠️ Le principe de Pauli est TOUJOURS vérifié !

2. Règle de Klechkowski (Ordre de Remplissage)

2.1 Les 2 Critères

  1. L'ordre de remplissage se fait par valeur de n+l croissantes
  2. En cas d'égalité de n+l, on remplit d'abord celle de plus faible n (couche la plus interne)

1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p...

2.5 Ordre de Remplissage vs Configuration Écrite

⚠️ Attention : L'ordre de remplissage (OR) n'est pas toujours l'ordre dans lequel on écrit la configuration !

Habituellement, on écrit par ordre de n croissant, puis par l croissant :

Exemple du Fer Fe (Z=26) :

  • Ordre de Remplissage : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁶
  • Configuration écrite : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁶(4s)²

2.6 Validité

La règle de Klechkowski est vérifiée pour l'état fondamental, PAS pour un état excité.

3. Règle de Hund (Règle du Spin Maximum)

3.1 L'Énoncé

Dans une sous-couche, le spin total doit être maximal.

Concrètement :

  • Les électrons occupent un maximum de cases quantiques dans une sous-couche possédant plusieurs orbitales
  • Dans une même sous-couche, les électrons célibataires possèdent des spins parallèles (même sens)

3.2 Exemple : Sous-couche 2p avec 4 électrons

ConfigurationRespecte Hund ?Commentaire
↑↓ ↑ ↑ ✅ OUI État fondamental (spin max = 1)
↑↓ ↑↓ ❌ NON État excité (spin = 0)
↑↓ ↑↓ ↑ ❌ IMPOSSIBLE 5 électrons, pas 4 !
↑↓ ↑↓ ❌ IMPOSSIBLE Violation de Pauli (3 cases max pour p)

3.3 Validité

La règle de Hund est vérifiée pour l'état fondamental, PAS pour un état excité.

⚠️ Important : La règle de Hund ne peut s'observer que si on écrit la configuration à l'aide des cases quantiques. On ne peut pas la vérifier avec une configuration écrite comme (1s)²(2s)²(2p)⁴.

4. Énergie des Systèmes Polyélectroniques

4.1 Le Problème

Pour un atome à N électrons, l'hamiltonien contient un terme de répulsion électron-électron qui rend la séparation des variables impossible → résolution exacte impossible !

4.2 Conséquence sur l'Énergie

Les orbitales obtenues sont semblables à celles de H, mais :

  • L'énergie dépend maintenant de n ET de l (levée de dégénérescence)
  • 2 sous-couches différentes n'auront pas la même énergie
  • C'est pour ça que 4s se remplit AVANT 3d (car E(4s) < E(3d))

5. Exemples de Configurations Électroniques

5.1 Carbone C (Z=6)

Configuration : (1s)²(2s)²(2p)²

Cases quantiques :

  • 1s : ↑↓
  • 2s : ↑↓
  • 2p : ↑ ↑ □ (règle de Hund : spins parallèles)

5.2 Oxygène O (Z=8)

Configuration : (1s)²(2s)²(2p)⁴

Cases quantiques :

  • 1s : ↑↓
  • 2s : ↑↓
  • 2p : ↑↓ ↑ ↑ (1 doublet + 2 célibataires)

5.3 Calcium Ca (Z=20)

Configuration : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²

→ Gaz noble précédent : Ar (Z=18) → on peut écrire [Ar] 4s²

5.4 Chrome Cr (Z=24) ⭐ EXCEPTION

Ordre de remplissage théorique : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁴

Configuration réelle (exception) : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)⁵

→ Écriture finale : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁵(4s)¹

Pourquoi ? La demi-couche d pleine (3d⁵) est plus stable que 3d⁴ 4s².

5.5 Cuivre Cu (Z=29) ⭐ EXCEPTION

Ordre de remplissage théorique : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁹

Configuration réelle (exception) : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)¹⁰

→ Écriture finale : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰(4s)¹

Pourquoi ? La sous-couche d pleine (3d¹⁰) est plus stable que 3d⁹ 4s².

5.6 Iode I (Z=53)

Ordre de remplissage : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁶(5s)²(4d)¹⁰(5p)⁵

Configuration écrite : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰(4s)²(4p)⁶(4d)¹⁰(5s)²(5p)⁵

5.7 Plomb Pb (Z=82)

Ordre de remplissage : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁶(5s)²(4d)¹⁰(5p)⁶(6s)²(4f)¹⁴(5d)¹⁰(6p)²

Configuration écrite : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰(4s)²(4p)⁶(4d)¹⁰(4f)¹⁴(5s)²(5p)⁶(5d)¹⁰(6s)²(6p)²

⚠️ Règle générale : Plus un élément est "profond" dans le tableau périodique, plus grandes sont les probabilités qu'il déroge à la règle de Klechkowski.

7. Méthode pour Écrire une Configuration Électronique

  1. Trouver Z (nombre de protons = nombre d'électrons pour un atome neutre)
  2. Appliquer Klechkowski : remplir les sous-couches dans l'ordre 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p...
  3. Respecter les capacités : s(2), p(6), d(10), f(14)
  4. Vérifier les exceptions : Cr, Cu, Mo, Ag, Au...
  5. Réécrire par ordre de n croissant pour la configuration finale
  6. Pour les cases quantiques : appliquer la règle de Hund (spins parallèles d'abord)

Exemple complet : Fer Fe (Z=26)

  1. Z = 26 → 26 électrons
  2. Remplissage : 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁶ (total = 2+2+6+2+6+2+6 = 26 ✓)
  3. Pas d'exception
  4. Configuration écrite : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁶(4s)²
  5. Cases quantiques pour 3d⁶ : ↑↓ ↑ ↑ ↑ ↑ (1 doublet + 4 célibataires, spins parallèles)

🎯 Points Clés à Retenir

  • Pauli : 2 électrons d'un même atome ne peuvent pas avoir les 4 mêmes nombres quantiques → 2 e⁻ max par orbitale (spins opposés)
  • Klechkowski : Remplissage par n+l croissants. En cas d'égalité, plus petit n d'abord
  • Hund : Dans une sous-couche, le spin total doit être maximal (électrons célibataires avec spins parallèles d'abord)
  • Capacités : s(2), p(6), d(10), f(14)
  • Ordre de remplissage : 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d...
  • Exceptions : Cr (3d⁵ 4s¹), Cu (3d¹⁰ 4s¹), Mo, Ag, Au
  • Configuration écrite : Par ordre de n croissant (pas l'ordre de remplissage)
  • Énergie polyélectronique : E dépend de n ET l (levée de dégénérescence)

⚠️ Pièges Classiques en QCM

  • Confusion OR vs Config écrite : L'ordre de remplissage n'est pas l'ordre d'écriture !
  • 4s avant 3d : 4s se remplit AVANT 3d, mais s'écrit APRÈS 3d dans la config finale
  • Exceptions : Cr et Cu sont les plus classiques en L1. À connaître par cœur !
  • Règle de Hund : Uniquement visible avec les cases quantiques, pas avec la config écrite
  • Spin-orbitale vs Orbitale : Une spin-orbitale = 1 e⁻ max. Une orbitale = 2 e⁻ max
  • État fondamental vs excité : Klechkowski et Hund ne sont vérifiés que pour l'état fondamental
  • Capacité des couches : Couche n = 2n² e⁻ max (pas n² !)
  • Vérification du total : La somme des électrons doit toujours égaler Z
