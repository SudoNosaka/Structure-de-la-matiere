Exercice 6.1 : Rayons atomiques - Comparaison

Classer les atomes suivants par rayon atomique croissant :

1°) Li, Na, K, Rb

2°) C, N, O, F

3°) Na, Mg, Al, Si

4°) O, S, Se, Te

💡 Aide de résolution

  • Le long d'une colonne (↓) : le rayon augmente (n augmente)
  • Le long d'une période (→) : le rayon diminue (Zeff augmente)

✅ Correction

1°) Li, Na, K, Rb (colonne 1) :

Li < Na < K < Rb

→ Le rayon augmente le long d'une colonne (n croissant)

2°) C, N, O, F (période 2) :

F < O < N < C

→ Le rayon diminue le long d'une période (Zeff croissant)

3°) Na, Mg, Al, Si (période 3) :

Si < Al < Mg < Na

→ Même raison que ci-dessus

4°) O, S, Se, Te (colonne 16) :

O < S < Se < Te

→ Le rayon augmente le long d'une colonne

Exercice 6.2 : Énergies d'ionisation successives

Voici les 5 premières énergies d'ionisation (en eV) d'un élément X :

EI1EI2EI3EI4EI5
5,1447,2971,6498,91138,39

1°) À quelle famille appartient l'élément X ?

2°) Identifier l'élément X.

3°) Expliquer la forte augmentation entre EI1 et EI2.

💡 Aide de résolution

  • Une forte augmentation entre EIn et EIn+1 indique qu'on a enlevé tous les électrons de valence
  • Le nombre d'électrons de valence = n
  • Comparer EI1 avec les valeurs connues

✅ Correction

1°) Famille :

On observe une très forte augmentation entre EI1 (5,14 eV) et EI2 (47,29 eV) : facteur ~9 !

→ Cela signifie que le 1er électron est un électron de valence, et le 2ème est un électron de cœur (beaucoup plus difficile à arracher).

L'élément X a donc 1 seul électron de valence → il appartient à la colonne 1 (alcalins).

2°) Identification :

EI1 = 5,14 eV correspond exactement à l'énergie d'ionisation du Sodium (Na).

Vérification : Na (Z=11) : (1s)²(2s)²(2p)⁶(3s)¹ → 1 électron de valence ✓

3°) Explication :

  • EI1 : on arrache l'électron 3s¹ (faiblement lié, Zeff faible)
  • EI2 : on arrache un électron 2p (couche interne, très fortement lié, Zeff élevé)
  • La différence énorme s'explique par le passage d'une couche de valence à une couche de cœur

Exercice 6.3 : Électronégativité

Classer les éléments suivants par électronégativité croissante :

1°) F, O, N, C

2°) Li, Na, K

3°) Na, Mg, Al, Si, P, S, Cl

4°) Quel est l'élément le plus électronégatif ? Le moins électronégatif ?

💡 Aide de résolution

  • Le long d'une période (→) : électronégativité augmente
  • Le long d'une colonne (↓) : électronégativité diminue
  • Le plus électronégatif : F (en haut à droite du tableau)
  • Le moins électronégatif : Fr ou Cs (en bas à gauche)

✅ Correction

1°) F, O, N, C (période 2, de droite à gauche) :

C < N < O < F

2°) Li, Na, K (colonne 1) :

K < Na < Li

3°) Na, Mg, Al, Si, P, S, Cl (période 3) :

Na < Mg < Al < Si < P < S < Cl

4°) Extrêmes :

  • Plus électronégatif : Fluor (F) - χ ≈ 4,0 (échelle de Pauling)
  • Moins électronégatif : Francium (Fr) ou Césium (Cs) - χ ≈ 0,7

Exercice 6.4 : Rayons ioniques

Classer les ions suivants par rayon ionique croissant :

1°) Na⁺, Mg²⁺, Al³⁺ (isoelectroniques : 10 électrons)

2°) F⁻, Na⁺, Mg²⁺ (isoelectroniques : 10 électrons)

3°) O²⁻, F⁻, Na⁺, Mg²⁺, Al³⁺ (isoelectroniques : 10 électrons)

4°) Conclure sur l'effet de la charge sur le rayon ionique pour des ions isoelectroniques.

💡 Aide de résolution

  • Ions isoelectroniques = même nombre d'électrons
  • Plus Z est grand, plus les électrons sont attirés par le noyau → rayon plus petit
  • Pour des ions isoelectroniques : rayon diminue quand Z augmente

✅ Correction

1°) Na⁺ (Z=11), Mg²⁺ (Z=12), Al³⁺ (Z=13) :

Al³⁺ < Mg²⁺ < Na⁺

→ Même nombre d'électrons (10), mais Z croissant → attraction nucléaire croissante → rayon décroissant

2°) F⁻ (Z=9), Na⁺ (Z=11), Mg²⁺ (Z=12) :

Mg²⁺ < Na⁺ < F⁻

3°) O²⁻ (Z=8), F⁻ (Z=9), Na⁺ (Z=11), Mg²⁺ (Z=12), Al³⁺ (Z=13) :

Al³⁺ < Mg²⁺ < Na⁺ < F⁻ < O²⁻

4°) Conclusion :

Pour des ions isoelectroniques (même nombre d'électrons) :

  • Le rayon ionique diminue quand Z augmente
  • Les cations (charge +) sont plus petits que les atomes neutres
  • Les anions (charge -) sont plus grands que les atomes neutres
  • Plus la charge positive est grande, plus l'ion est petit

Exercice 6.5 : Anomalies dans les énergies d'ionisation

On observe que EI1(O) < EI1(N) alors que O est à droite de N dans le tableau.

1°) Écrire les configurations électroniques de N et O.

2°) Représenter les cases quantiques de la sous-couche 2p pour N et O.

3°) Expliquer l'anomalie observée.

4°) Même question pour Be et B.

💡 Aide de résolution

  • Penser à la stabilité des configurations (demi-couche pleine, sous-couche pleine)
  • Penser à la répulsion entre électrons appariés dans une même orbitale

✅ Correction

1°) Configurations :

  • N (Z=7) : (1s)²(2s)²(2p)³
  • O (Z=8) : (1s)²(2s)²(2p)⁴

2°) Cases quantiques 2p :

N (2p³) : ↑   ↑   ↑
O (2p⁴) : ↑↓   ↑   ↑

3°) Explication de l'anomalie N/O :

  • N a une demi-couche 2p pleine (3 électrons célibataires) → configuration particulièrement stable → difficile à ioniser
  • O a 4 électrons 2p : 1 doublet + 2 célibataires. Les 2 électrons du doublet sont dans la même orbitale → répulsion électron-électron → l'un d'eux est plus facile à arracher
  • → EI1(O) < EI1(N) malgré Z(O) > Z(N)

4°) Anomalie Be/B :

  • Be (Z=4) : (1s)²(2s)² → sous-couche 2s pleine (stable)
  • B (Z=5) : (1s)²(2s)²(2p)¹ → 1 électron 2p (moins bien protégé)
  • L'électron 2p de B est moins bien écranté que les électrons 2s de Be → plus facile à arracher
  • → EI1(B) < EI1(Be)

Exercice 6.6 : Caractère métallique

Classer les éléments suivants par caractère métallique croissant :

1°) Na, Mg, Al, Si, P, S, Cl

2°) B, Al, Ga, In, Tl

3°) Parmi les éléments suivants, lesquels sont des métaux ? Des non-métaux ? Des métalloïdes ?

C, Si, Ge, Sn, Pb, N, P, As, Sb, Bi

💡 Aide de résolution

  • Le caractère métallique diminue le long d'une période (→)
  • Le caractère métallique augmente le long d'une colonne (↓)
  • Métaux : gauche du tableau | Non-métaux : droite | Métalloïdes : frontière

✅ Correction

1°) Période 3 :

Cl < S < P < Si < Al < Mg < Na

→ Caractère métallique décroissant de gauche à droite

2°) Colonne 13 :

B < Al < Ga < In < Tl

→ Caractère métallique croissant de haut en bas

3°) Classification :

TypeÉléments
MétauxSn, Pb, Sb, Bi
Non-métauxC, N, P
MétalloïdesSi, Ge, As

Note : La frontière entre métaux et non-métaux suit une ligne diagonale dans le tableau périodique (de B à Po). Les éléments proches de cette ligne sont des métalloïdes.

Exercice 6.7 : Affinité électronique

L'affinité électronique est l'énergie libérée lorsqu'un atome gazeux capte un électron :

X(g) + e⁻ → X⁻(g) + énergie

1°) Pourquoi l'affinité électronique des gaz nobles est-elle proche de zéro (voire positive) ?

2°) Pourquoi les halogènes ont-ils une affinité électronique très élevée ?

3°) Pourquoi l'affinité électronique de l'oxygène est-elle plus faible que celle du soufre ?

💡 Aide de résolution

  • Penser à la stabilité des configurations électroniques
  • Penser à la répulsion électron-électron dans les petites orbitales

✅ Correction

1°) Gaz nobles :

  • Configuration ns² np⁶ (couche externe pleine) → très stable
  • Ajouter un électron nécessiterait de le placer dans la couche (n+1), très éloignée du noyau
  • → Affinité électronique proche de zéro ou positive (il faut fournir de l'énergie)

2°) Halogènes :

  • Configuration ns² np⁵ → il manque 1 électron pour atteindre la configuration du gaz noble
  • Capter un électron permet d'atteindre ns² np⁶ (très stable)
  • → Affinité électronique très élevée (énergie libérée importante)
  • Exemple : F : 328 kJ/mol | Cl : 349 kJ/mol

3°) Anomalie O/S :

  • O : AE = 141 kJ/mol | S : AE = 200 kJ/mol
  • L'atome d'oxygène est très petit → la densité électronique est très élevée
  • Quand on ajoute un électron à O, il subit une forte répulsion des autres électrons (orbitale 2p petite et dense)
  • Le soufre est plus grand → moins de répulsion → affinité électronique plus élevée
  • → Même anomalie observée pour F/Cl et N/P

Exercice 6.8 : Synthèse - Prédiction de réactivité

On considère les éléments suivants : Na, Mg, Al, Si, P, S, Cl

1°) Quel est l'élément le plus réactif pour former un cation ? Pourquoi ?

2°) Quel est l'élément le plus réactif pour former un anion ? Pourquoi ?

3°) Quel composé ionique formerez-vous entre Na et Cl ? Entre Mg et Cl ?

4°) Quel est le caractère acide/base de l'oxyde de Na (Na₂O) ? De l'oxyde de Cl (Cl₂O₇) ?

💡 Aide de résolution

  • Pour former un cation : faible énergie d'ionisation → caractère métallique
  • Pour former un anion : forte affinité électronique → caractère non-métallique
  • Oxydes métalliques = basiques | Oxydes non-métalliques = acides

✅ Correction

1°) Cation :

  • L'élément le plus réactif pour former un cation est Na
  • Car c'est le plus métallique (colonne 1, faible EI, 1 électron de valence facile à perdre)
  • Na → Na⁺ + e⁻ (EI₁ = 5,14 eV, très faible)

2°) Anion :

  • L'élément le plus réactif pour former un anion est Cl
  • Car c'est le plus non-métallique (colonne 17, forte AE, 1 électron manquant pour l'octet)
  • Cl + e⁻ → Cl⁻ (AE = 349 kJ/mol, très élevée)

3°) Composés ioniques :

  • Na + Cl → NaCl (chlorure de sodium)
  • Mg + 2Cl → MgCl₂ (chlorure de magnésium)

4°) Caractère des oxydes :

  • Na₂O : oxyde métallique → basique
  • Na₂O + H₂O → 2NaOH (base forte)
  • Cl₂O₇ : oxyde non-métallique → acide
  • Cl₂O₇ + H₂O → 2HClO₄ (acide perchlorique, acide fort)

Règle générale : Le long d'une période, le caractère des oxydes passe de basique → amphotère → acide.
