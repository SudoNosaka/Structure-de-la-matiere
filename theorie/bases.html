Puissances de 10

(10ⁿ)ᵐ = 10ⁿˣᵐ

Logarithmes

ln(2) ≈ 0,693
ln(e) = 1 | ln(1) = 0
ln(a × b) = ln(a) + ln(b)
ln(a/b) = ln(a) - ln(b)
ln(aⁿ) = n × ln(a)
ln(eˣ) = x | e^(ln(x)) = x

Dérivées usuelles

d/dx (e^(kx)) = k · e^(kx)
d/dx (xⁿ) = n · xⁿ⁻¹

La dérivée représente la vitesse de variation d'une fonction.

Équation différentielle du 1er ordre

dy/dt = -k·y → y(t) = y₀ · e^(-k·t)

C'est la forme de la loi de désintégration radioactive.

Résoudre une équation exponentielle

Pour résoudre eˣ = a :

x = ln(a)

Pour résoudre A(t) = A₀ · e^(-λt) en trouvant t :

t = -ln(A(t)/A₀) / λ

Physique & Chimie

Structure de l'Atome

ᴬ_Z X : Z = protons | A = nucléons | N = A - Z = neutrons
  • Atome neutre : nombre d'électrons = Z
  • Ion : nombre d'électrons = Z - charge
  • Isotopes : même Z, A différent (mêmes propriétés chimiques)
  • Isobares : même A, Z différent
  • Isotones : même N, Z différent

Radioactivité

α : ⁴₂He (peu pénétrant) | β⁻ : ⁰₋₁e | γ : photon (très pénétrant)
N(t) = N₀ · e^(-λt)
T = ln(2)/λ ≈ 0,693/λ
A(t) = λ·N(t) (en Bq, 1 Bq = 1 désintégration/s)
  • Conservation de A et Z dans les réactions nucléaires
  • Défaut de masse : Δm = Z·mp + N·mn - mnoyau
  • Énergie de liaison : El = Δm × 931,5 MeV

Effet Photoélectrique (Einstein, 1905)

Ephoton = h·ν = h·c/λ
h·ν = W + ½·m·v²
  • W = travail d'extraction (énergie seuil)
  • Si ν < ν₀ : aucun électron éjecté
  • L'intensité change le nombre d'électrons, pas leur énergie

Dualité Onde-Corpuscule (de Broglie, 1923)

λ = h/p = h/(m·v)
  • Toute particule a une longueur d'onde associée
  • Macroscopique : λ indétectable
  • Microscopique : λ observable (diffraction)

Principe d'Incertitude (Heisenberg, 1927)

Δx · Δp ≥ ħ/2
ħ = h/(2π) = 1,055 × 10⁻³⁴ J·s
  • Limite fondamentale de la nature, pas technique
  • Version énergie/temps : ΔE · Δt ≥ ħ/2

Modèle de Bohr (1913)

Eₙ = -13,6 × Z²/n² eV
rₙ = n² × a₀ / Z
|ΔE| = h·ν = h·c/λ
  • n = 1, 2, 3... (nombre quantique principal)
  • n=1 : état fondamental | n>1 : états excités | n→∞ : ionisation
  • Ne fonctionne que pour les atomes hydrogénoïdes (1 électron)

Configuration Électronique

Ordre : 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d...
  • Pauli : 2 e⁻ max par orbitale (spins opposés)
  • Klechkowski : Remplissage par n+l croissants
  • Hund : Maximiser les spins parallèles
  • Exceptions : Cr (3d⁵ 4s¹), Cu (3d¹⁰ 4s¹), Mo, Ag, Au
L'ordre de remplissage ≠ l'ordre d'écriture ! On écrit par ordre de n croissant.

Structure de Lewis

  • Représenter les électrons de valence (points ou tirets)
  • Règle de l'octet : Atomes stables avec 8 e⁻ de valence (2 pour H, He)
  • Liaison covalente = doublet partagé
  • Doublet non-liant = doublet libre
  • Charge formelle = nb e⁻ valence - (nb e⁻ non-liants + nb liaisons)
