Mathématiques

Puissances de 10

10ⁿ × 10ᵐ = 10ⁿ⁺ᵐ
10ⁿ / 10ᵐ = 10ⁿ⁻ᵐ
(10ⁿ)ᵐ = 10ⁿˣᵐ
a × 10ⁿ × b × 10ᵐ = (a×b) × 10ⁿ⁺ᵐ

Logarithmes

ln(2) ≈ 0,693
ln(e) = 1 | ln(1) = 0
ln(a × b) = ln(a) + ln(b)
ln(a/b) = ln(a) - ln(b)
ln(aⁿ) = n × ln(a)
ln(eˣ) = x | e^(ln(x)) = x

Dérivées usuelles

d/dx (e^(kx)) = k · e^(kx)
d/dx (xⁿ) = n · xⁿ⁻¹

Équation différentielle du 1er ordre

dy/dt = -k·y → y(t) = y₀ · e^(-k·t)

Résoudre une équation exponentielle

eˣ = a → x = ln(a)
A(t) = A₀ · e^(-λt) → t = -ln(A(t)/A₀) / λ

Physique & Chimie

Structure de l'Atome

ᴬ_Z X : Z = protons | A = nucléons | N = A - Z
  • Atome neutre : électrons = Z
  • Ion : électrons = Z - charge
  • Isotopes : même Z, A différent

Radioactivité

α : ⁴₂He | β⁻ : ⁰₋₁e | γ : photon
N(t) = N₀ · e^(-λt)
T = ln(2)/λ ≈ 0,693/λ
A(t) = λ·N(t) (en Bq)

Effet Photoélectrique

E = h·ν = h·c/λ
h·ν = W + ½·m·v²

Dualité Onde-Corpuscule

λ = h/p = h/(m·v)

Principe d'Incertitude

Δx · Δp ≥ ħ/2

Modèle de Bohr

Eₙ = -13,6 × Z²/n² eV
rₙ = n² × a₀ / Z
