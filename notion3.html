📖 Introduction : Vers la Mécanique Quantique

À la fin du 19ème siècle, les physiciens pensaient avoir tout compris... jusqu'à ce que 2 phénomènes viennent bouleverser la physique classique :

  • L'effet photoélectrique → la lumière se comporte aussi comme des particules (photons)
  • Les spectres de raies → l'énergie des électrons dans l'atome est quantifiée

Ces observations ont mené au modèle de Bohr (1913), puis à la mécanique quantique (1925-1927) avec de Broglie, Heisenberg et Schrödinger.

1. L'Effet Photoélectrique (Einstein, 1905)

1.1 L'Expérience

On éclaire une plaque métallique avec de la lumière. Des électrons sont éjectés. Observations surprenantes :

  • Si la fréquence ν < ν₀ (fréquence seuil) : aucun électron n'est éjecté, quelle que soit l'intensité
  • Si ν > ν₀ : l'énergie cinétique des électrons dépend linéairement de ν, pas de l'intensité
  • L'intensité lumineuse change le nombre d'électrons éjectés, mais pas leur énergie

⚠️ Ces résultats contredisent la théorie ondulatoire classique !

1.2 L'Explication d'Einstein

La lumière est constituée de grains d'énergie appelés photons. Chaque photon a une énergie :

E = h·ν = h·c/λ

Où h = 6,626 × 10⁻³⁴ J·s est la constante de Planck.

L'équation de l'effet photoélectrique :

h·ν = W + ½·m·v²

Où W = h·ν₀ est le travail d'extraction (énergie minimale pour arracher l'électron).

2. Spectres d'Émission et d'Absorption

2.1 Observation

Quand on chauffe un gaz (ex: hydrogène) ou qu'on le soumet à une décharge électrique, il émet de la lumière. En décomposant cette lumière avec un prisme, on observe un spectre de raies (pas un spectre continu).

→ Seules certaines fréquences sont émises. L'énergie des électrons dans l'atome est donc quantifiée.

2.2 Formule de Rydberg (pour l'hydrogène)

1/λ = RH · (1/n² - 1/p²)

Avec :

  • RH = 1,097 × 10⁷ m⁻¹ (constante de Rydberg)
  • n et p sont des entiers, avec p > n

3. Le Modèle de Bohr (1913)

3.1 Les 4 Postulats de Bohr

  1. L'électron ne peut se trouver que dans des états stationnaires d'énergie bien définie (orbites circulaires)
  2. Dans un état stationnaire, l'atome n'émet pas de rayonnement
  3. L'émission/absorption d'un photon se fait lors d'une transition entre 2 niveaux : h·ν = |ΔE|
  4. Le moment angulaire de l'électron est quantifié : L = n·h/(2π)

3.2 Énergie de l'Électron (Atome Hydrogénoïde)

Pour un atome à 1 seul électron (H, He⁺, Li²⁺...) de numéro atomique Z :

En = -13,6 × (Z²/n²) eV

Où n = 1, 2, 3... est le nombre quantique principal.

Interprétation :

  • L'énergie est négative → énergie de liaison (il faut fournir de l'énergie pour arracher l'électron)
  • n = 1 : état fondamental (énergie la plus basse, la plus stable)
  • n > 1 : états excités
  • n → ∞ : E → 0, l'électron est arraché (ionisation)

3.3 Rayon de l'Orbite

rn = n² × a₀ / Z

Avec a₀ = 5,29 × 10⁻¹¹ m = 0,529 Å (rayon de Bohr, rayon de la première orbite de l'hydrogène).

3.4 Exemple : Hydrogène (Z=1)

  • n=1 : r₁ = 0,529 Å, E₁ = -13,6 eV
  • n=2 : r₂ = 4 × 0,529 = 2,12 Å, E₂ = -13,6/4 = -3,4 eV
  • n=3 : r₃ = 9 × 0,529 = 4,76 Å, E₃ = -13,6/9 = -1,51 eV

3.5 Transition Électronique

Lors d'une transition du niveau p vers le niveau n (p > n), un photon est émis :

|ΔE| = Ep - En = h·ν = h·c/λ

Exemple : Transition n=3 → n=2 de l'hydrogène (raie Hα de Balmer, rouge) :

  • ΔE = -1,51 - (-3,4) = 1,89 eV
  • λ = h·c/ΔE = (6,626×10⁻³⁴ × 3×10⁸) / (1,89 × 1,6×10⁻¹⁹) = 656 nm (rouge)

3.6 Limites du Modèle de Bohr

  • ❌ Ne fonctionne que pour les atomes hydrogénoïdes (1 électron)
  • ❌ Ne peut pas expliquer les spectres des atomes polyélectroniques
  • ❌ Ne donne pas d'explication à la liaison chimique
  • ❌ D'après l'électromagnétisme classique, l'électron en orbite devrait rayonner et s'écraser sur le noyau !

→ Il fallait une nouvelle mécanique : la mécanique quantique.

4. La Dualité Onde-Corpuscule (de Broglie, 1923)

4.1 Le Principe

Si la lumière (onde) peut se comporter comme une particule (photon), alors la matière (particule) peut se comporter comme une onde !

Toute particule de quantité de mouvement p = m·v a une longueur d'onde associée :

λ = h/p = h/(m·v)

4.2 Exemples

  • Balle de baseball (m=140 g, v=40 m/s) : λ = 1,18 × 10⁻³⁴ m → indétectable (comportement corpusculaire)
  • Électron (m=9,1 × 10⁻³¹ kg, v=1% de c) : λ = 2,42 × 10⁻¹⁰ m = 2,42 Å → observable (comportement ondulatoire)

✅ Confirmé expérimentalement par Davisson et Germer (1925) : diffraction d'électrons par un cristal.

5. Le Principe d'Incertitude de Heisenberg (1927)

5.1 L'Énoncé

Il est impossible de connaître simultanément avec une précision infinie :

  • La position x d'une particule
  • La quantité de mouvement p = m·v de cette particule
Δx · Δp ≥ ħ/2

Où ħ = h/(2π) = 1,055 × 10⁻³⁴ J·s (constante de Planck réduite).

5.2 Interprétation

Ce n'est PAS un problème de précision des instruments ! C'est une limite fondamentale de la nature, due à la dualité onde-corpuscule.

  • Si on localise précisément l'électron (Δx petit) → Δp devient grand (vitesse très incertaine)
  • Si on connaît précisément la vitesse (Δp petit) → Δx devient grand (position très incertaine)

5.3 Autre Forme : Énergie-Temps

ΔE · Δt ≥ ħ/2

5.4 Conséquence

On ne peut plus parler de trajectoire classique pour un électron. On utilise une fonction d'onde ψ qui donne une description probabiliste de la position de l'électron.

6. La Mécanique Quantique : Orbitales Atomiques

6.1 Fonction d'Onde et Orbitale

L'électron est décrit par une fonction d'onde ψ(x,y,z), solution de l'équation de Schrödinger.

Le carré |ψ|² représente la densité de probabilité de présence de l'électron en un point.

Une orbitale atomique (OA) est la région de l'espace où la probabilité de trouver l'électron est élevée (≈ 90%).

6.2 Les 4 Nombres Quantiques

Chaque électron dans un atome est caractérisé par 4 nombres quantiques :

Nombre Symbole Valeurs Définit
Principal n 1, 2, 3, ... Couche électronique (taille, énergie)
Azimutal (secondaire) l 0, 1, ..., n-1 Sous-couche (forme de l'OA)
Magnétique ml -l, ..., 0, ..., +l Orientation de l'OA dans l'espace
Spin ms +½ ou -½ Sens de rotation de l'électron sur lui-même

7. Configuration Électronique

7.1 Les 3 Règles à Respecter

① Principe d'exclusion de Pauli :

Deux électrons d'un même atome ne peuvent pas avoir les 4 mêmes nombres quantiques. Donc une orbitale ne peut contenir que 2 électrons max, de spins opposés.

② Règle de Klechkowski :

Les électrons remplissent les sous-couches par ordre d'énergie croissante :

1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s...

Astuce : Remplir par diagonales (règle de la diagonale) :

1s
2s  2p
3s  3p  3d
4s  4p  4d  4f
5s  5p  5d  5f
6s  6p  6d
7s  7p

③ Règle de Hund (règle du spin maximum) :

Lorsqu'une sous-couche possède plusieurs orbitales dégénérées (même énergie, ex: les 3 orbitales p), les électrons se répartissent d'abord un par un avec des spins parallèles, avant de s'apparier.

7.2 Exemples de Configurations

Hydrogène H (Z=1) : 1s¹

Hélium He (Z=2) : 1s²

Carbone C (Z=6) : 1s² 2s² 2p²

→ En détail : 2px¹ 2py¹ 2pz⁰ (règle de Hund : spins parallèles)

Oxygène O (Z=8) : 1s² 2s² 2p⁴

→ En détail : 2px² 2py¹ 2pz¹

Fer Fe (Z=26) : 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁶

Ou en notation condensée : [Ar] 4s² 3d⁶

7.3 Électrons de Valence

Les électrons de valence sont ceux de la couche externe (n le plus grand). Ils déterminent les propriétés chimiques de l'élément.

Exemple : Carbone → couche externe n=2 → 4 électrons de valence (2s² 2p²)

🎯 Points Clés à Retenir

  • Effet photoélectrique : E = h·ν (la lumière est quantifiée en photons)
  • Spectres de raies → énergie quantifiée dans l'atome
  • Modèle de Bohr : En = -13,6 × Z²/n² eV (atomes hydrogénoïdes uniquement)
  • Dualité onde-corpuscule : λ = h/(m·v)
  • Heisenberg : Δx·Δp ≥ ħ/2 (limite fondamentale, pas technique)
  • 4 nombres quantiques : n, l, ml, ms
  • Sous-couches : s(2e⁻), p(6e⁻), d(10e⁻), f(14e⁻)
  • Configuration électronique : Pauli + Klechkowski + Hund

⚠️ Pièges Classiques en QCM

  • Valeurs de l : l va de 0 à n-1 (pas de 1 à n !). Donc pour n=2, l = 0 ou 1 (pas 2)
  • Valeurs de ml : de -l à +l (incluant 0). Pour l=1, ml = -1, 0, +1
  • Ordre de remplissage : 4s se remplit AVANT 3d (mais 4s se vide AVANT 3d pour les ions !)
  • Règle de Hund : Les électrons se mettent d'abord célibataires avec spins parallèles
  • Modèle de Bohr : Uniquement pour H, He⁺, Li²⁺... (1 seul électron)
  • Unités d'énergie : 1 eV = 1,6 × 10⁻¹⁹ J (conversion fréquente)
  • Énergie négative : Plus E est négative, plus l'électron est lié (stable)
