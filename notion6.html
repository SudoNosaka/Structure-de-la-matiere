📖 Introduction : Le Problème des Atomes Polyélectroniques

Dans la Notion 5, nous avons vu que pour un atome à N électrons (ex: Hélium avec 2 e⁻), l'hamiltonien contient un terme de répulsion électron-électron qui rend la résolution exacte impossible.

→ Il faut utiliser des approximations pour pouvoir calculer l'énergie des électrons dans les atomes polyélectroniques.

Dans cette notion, nous allons voir :

  1. L'approximation hydrogénoïde (effet d'écran)
  2. La méthode de Slater (calcul de Zeff)
  3. Le tableau périodique et sa structure

1. L'Approximation Hydrogénoïde

1.1 Le Problème

Prenons l'exemple de l'atome d'Hélium (noyau +2e, 2 électrons) :

Ĥ = Ece1 + VN-e1 + Ece2 + VN-e2 + Ve1-e2

Le terme Ve1-e2 (répulsion entre les 2 électrons) rend la séparation des variables impossible.

1.2 L'Idée de l'Approximation

Considérons 2 cas limites pour l'électron 2 :

  • Cas 1 : L'électron 2 est très proche du noyau → il ressent la charge +2 (pas d'écran)
  • Cas 2 : L'électron 2 est très éloigné → il ressent une charge globale de +1 (+2 du noyau -1 de l'électron 1 qui fait écran)

→ La charge ressentie par l'électron 2 varie entre +1 et +2.

1.3 L'Effet d'Écran

L'effet d'écran est la diminution de la charge nucléaire ressentie par un électron due à la présence des autres électrons.

On définit la charge nucléaire effective :

Zeff = Z - σ

Où :

  • Z : numéro atomique (charge réelle du noyau)
  • σ : constante d'écran (0 ≤ σ ≤ Z-1)
  • Zeff : charge effective ressentie par l'électron

1.4 Énergie dans l'Approximation Hydrogénoïde

On considère que chaque électron est soumis à la charge +Z du noyau corrigée de l'effet d'écran des autres électrons.

L'énergie d'un électron dans une sous-couche quelconque vaut alors :

En = -13,6 × (Zeff² / n²) eV

C'est la même formule que pour l'atome H, mais avec Zeff au lieu de Z.

2. L'Approximation de Slater

2.1 Le Principe

Grâce à l'approximation hydrogénoïde, on peut calculer l'énergie d'un électron d'une sous-couche quelconque si l'on connaît Zeff.

La méthode de Slater permet de calculer σ (et donc Zeff) de manière empirique.

2.2 Les Règles de Slater

Pour calculer σ pour un électron i :

σ(i) = Σj≠i σj→i

Où σj→i est la contribution de l'électron j à l'écran de l'électron i.

2.3 Tableau des Paramètres de Slater

Électron i ↓ / Électron j → 1s 2s, 2p 3s, 3p 3d 4s, 4p
1s 0,31 0,85 1,00 1,00 1,00
2s, 2p 0 0,35 0,85 1,00 1,00
3s, 3p 0 0 0,35 0,85 1,00
3d 0 0 0 0,35 0,85
4s, 4p 0 0 0 0 0,35

2.4 Règles Importantes

  • Un électron n'est pas "écranté" par lui-même (diagonale = 0)
  • Un électron d'une couche externe n'a pas d'effet d'écran sur un électron d'une couche plus interne (valeurs = 0)
  • On retrouve la même énergie pour une sous-couche ns et np → conséquence des paramètres de Slater

💡 À retenir

Pour un électron dans une sous-couche (ns, np) :

  • Les autres électrons de la même sous-couche contribuent à hauteur de 0,35
  • Les électrons de la couche (n-1) contribuent à hauteur de 0,85
  • Les électrons des couches ≤ (n-2) contribuent à hauteur de 1,00

Pour un électron dans une sous-couche nd :

  • Les autres électrons de la même sous-couche : 0,35
  • Tous les électrons des couches ≤ (n-1) : 1,00

3. Exemple Détaillé : L'Azote N (Z=7)

3.1 Configuration Électronique

N (Z=7) : (1s)²(2s)²(2p)³

3.2 Calcul de Zeff pour 1s

Pour un électron 1s :

  • 1 autre électron 1s : 1 × 0,31 = 0,31
  • Électrons 2s, 2p : 0 (couche externe, pas d'effet d'écran)
σ(1s) = 0,31
Zeff(1s) = 7 - 0,31 = 6,69
E1s = -13,6 × (6,69² / 1²) = -608,68 eV

3.3 Calcul de Zeff pour 2s

Pour un électron 2s :

  • 1 autre électron 2s : 1 × 0,35 = 0,35
  • 3 électrons 2p : 3 × 0,35 = 1,05
  • 2 électrons 1s : 2 × 0,85 = 1,70
σ(2s) = 0,35 + 1,05 + 1,70 = 3,10
Zeff(2s) = 7 - 3,10 = 3,90
E2s = -13,6 × (3,90² / 2²) = -51,71 eV

3.4 Calcul de Zeff pour 2p

Pour un électron 2p :

  • 2 autres électrons 2p : 2 × 0,35 = 0,70
  • 2 électrons 2s : 2 × 0,35 = 0,70
  • 2 électrons 1s : 2 × 0,85 = 1,70
σ(2p) = 0,70 + 0,70 + 1,70 = 3,10
Zeff(2p) = 7 - 3,10 = 3,90
E2p = -13,6 × (3,90² / 2²) = -51,71 eV = E2s

3.5 Énergie Totale de l'Atome N

Etot(N) = 2×(-608,68) + 2×(-51,71) + 3×(-51,71) = -1475,93 eV

4. Application : Énergie d'Ionisation

4.1 Ion N⁺ dans l'État Fondamental

N⁺ (Z=7) : (1s)²(2s)²(2p)²

Calcul de Zeff pour 2s/2p :

  • 1 autre électron 2s : 1 × 0,35 = 0,35
  • 2 électrons 2p : 2 × 0,35 = 0,70
  • 2 électrons 1s : 2 × 0,85 = 1,70
σ(2s) = σ(2p) = 0,35 + 0,70 + 1,70 = 2,75
Zeff(2s) = Zeff(2p) = 7 - 2,75 = 4,25
E2s = E2p = -13,6 × (4,25² / 2²) = -61,41 eV
Etot(N⁺) = 2×(-608,68) + 2×(-61,41) + 2×(-61,41) = -1463,01 eV

4.2 Énergie d'Ionisation

Pour arracher un électron N → N⁺ + e⁻ :

ΔE = E(N⁺) - E(N) = -1463,01 - (-1475,93) = 12,92 eV

Le photon correspondant a une longueur d'onde :

λ = hc/ΔE = 96,1 nm (ultraviolet)

4.3 Ion N⁺ dans l'État Excité

N⁺* (Z=7) : (1s)¹(2s)²(2p)³

Calcul de Zeff :

  • Pour 1s : σ(1s) = 0 (pas d'autre électron 1s) → Zeff(1s) = 7
  • E1s = -13,6 × (7² / 1²) = -666,4 eV
  • Pour 2s/2p : σ = 1×0,85 + 3×0,35 + 0,35 = 2,25 → Zeff = 4,75
  • E2s = E2p = -13,6 × (4,75² / 2²) = -76,71 eV
Etot(N⁺*) = 1×(-666,4) + 2×(-76,71) + 3×(-76,71) = -1049,96 eV

Pour arracher un électron N → N⁺* + e⁻ :

ΔE = 426 eV → λ = 2,91 nm (rayons X)

5. Le Tableau Périodique

5.1 Historique

1864 : Première classification à 1 seule entrée (masse atomique croissante)

1869 : Mendeleïev a l'idée d'un classement à 2 entrées :

  • Masse atomique croissante
  • Éléments ayant des propriétés similaires ensemble

Il laisse des cases vides pour les éléments pas encore découverts → ils seront découverts ultérieurement !

1913 : Les éléments sont classés par numéro atomique Z croissant (plus pertinent que la masse).

5.2 Structure du Tableau Périodique

  • 7 lignes ≡ 7 périodes (de longueurs variables)
  • 18 colonnes ≡ 18 familles
  • 4 blocs : s, p, d, f

5.3 Les Blocs

Bloc Sous-couche de valence Colonnes Éléments
s ns¹ ou ns² 1-2 (IA, IIA) Alcalins, Alcalino-terreux
p np¹ à np⁶ 13-18 (IIIA à VIIIA) Métaux pauvres, Métalloïdes, Non-métaux, Gaz nobles
d (n-1)d¹ à (n-1)d¹⁰ 3-12 (IIIB à IIB) Métaux de transition
f (n-2)f¹ à (n-2)f¹⁴ Lanthanides (57-71) et Actinides (89-103) Terres rares

5.4 Les Familles Importantes

Famille Colonne Configuration de valence Exemples
Alcalins 1 (IA) ns¹ Li, Na, K, Rb, Cs
Alcalino-terreux 2 (IIA) ns² Be, Mg, Ca, Sr, Ba
Halogènes 17 (VIIA) ns² np⁵ F, Cl, Br, I
Gaz nobles 18 (VIIIA) ns² np⁶ (sauf He: 1s²) He, Ne, Ar, Kr, Xe

5.5 Propriétés Périodiques

Les éléments d'une même colonne (famille) ont des propriétés chimiques similaires car ils ont la même configuration électronique de valence.

Exemple : tous les alcalins (Li, Na, K...) ont 1 électron de valence ns¹ → ils forment tous des ions M⁺.

🎯 Points Clés à Retenir

  • Effet d'écran : Diminution de la charge nucléaire ressentie par un électron due aux autres électrons
  • Zeff = Z - σ (charge effective = charge réelle - constante d'écran)
  • Méthode de Slater : Permet de calculer σ de manière empirique
  • Énergie : En = -13,6 × (Zeff² / n²) eV
  • Règles de Slater : Même sous-couche : 0,35 | Couche (n-1) : 0,85 | Couches ≤ (n-2) : 1,00
  • Pour nd : Même sous-couche : 0,35 | Tout le reste : 1,00
  • Tableau périodique : Classé par Z croissant, 7 périodes, 18 colonnes, 4 blocs (s, p, d, f)
  • Familles : Même colonne = même configuration de valence = propriétés similaires

⚠️ Pièges Classiques en QCM

  • Un électron n'écrante pas lui-même : Ne pas compter l'électron dont on calcule Zeff
  • Couches externes : Les électrons d'une couche externe n'ont PAS d'effet d'écran sur une couche interne (σ = 0)
  • ns et np : Avec Slater, E(ns) = E(np) (même Zeff)
  • Calcul de σ : Bien distinguer les contributions selon la sous-couche considérée (ns/np vs nd)
  • Blocs du tableau : Le bloc d correspond aux métaux de transition (colonnes 3-12)
  • Gaz nobles : Configuration ns² np⁶ (sauf He qui est 1s²)
  • Énergie d'ionisation : ΔE = E(ion) - E(atome) > 0 (il faut fournir de l'énergie)
