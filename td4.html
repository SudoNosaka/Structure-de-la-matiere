📋 Rappels essentiels

Les 3 règles fondamentales

  • ① Principe de Pauli : 2 électrons d'un même atome ne peuvent pas avoir les 4 mêmes nombres quantiques → 2 électrons max par orbitale (spins opposés)
  • ② Règle de Klechkowski : Remplissage par n+l croissants. En cas d'égalité, plus petit n d'abord
  • ③ Règle de Hund : Dans une sous-couche, le spin total doit être maximal (électrons célibataires avec spins parallèles d'abord)

Ordre de remplissage

1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d...

Exercice 4.3 : Exceptions à la règle de Klechkowski

Donner la configuration électronique réelle des atomes suivants :

1°) Cr (Z=24)

2°) Cu (Z=29)

3°) Expliquer pourquoi ces configurations sont des exceptions.

💡 Aide de résolution

  • Cr : la demi-couche 3d⁵ est plus stable que 3d⁴
  • Cu : la sous-couche 3d¹⁰ pleine est plus stable que 3d⁹
  • Un électron passe de 4s à 3d pour atteindre cette stabilité

✅ Correction

1°) Cr (Z=24) :

Configuration théorique (Klechkowski) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁴

Configuration réelle (exception) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)⁵

Écrite par ordre de n : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁵(4s)¹

2°) Cu (Z=29) :

Configuration théorique :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁹

Configuration réelle (exception) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)¹⁰

Écrite par ordre de n : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰(4s)¹

3°) Explication :

  • Cr : La demi-couche d pleine (3d⁵, avec 5 électrons célibataires de spins parallèles) est particulièrement stable. Un électron passe de 4s à 3d pour atteindre cette configuration.
  • Cu : La sous-couche d pleine (3d¹⁰) est particulièrement stable. Un électron passe de 4s à 3d pour atteindre cette configuration.
  • Ces exceptions sont dues à des effets de stabilité quantique (échange d'électrons de même spin).

Exercice 4.4 : Électrons de valence

Pour chaque atome, donner :

  • La configuration électronique
  • Le nombre d'électrons de valence
  • La famille chimique (colonne du tableau périodique)

1°) Mg (Z=12)

2°) Si (Z=14)

3°) Br (Z=35)

4°) Kr (Z=36)

💡 Aide de résolution

  • Les électrons de valence sont ceux de la couche externe (n le plus grand)
  • La famille est déterminée par le nombre d'électrons de valence
  • Colonne 1-2 : bloc s | Colonne 13-18 : bloc p

✅ Correction

1°) Mg (Z=12) :

(1s)²(2s)²(2p)⁶(3s)²
  • Électrons de valence : 2 (3s²)
  • Famille : Alcalino-terreux (colonne 2)

2°) Si (Z=14) :

(1s)²(2s)²(2p)⁶(3s)²(3p)²
  • Électrons de valence : 4 (3s² 3p²)
  • Famille : Colonne 14 (comme le carbone)

3°) Br (Z=35) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁵
  • Électrons de valence : 7 (4s² 4p⁵)
  • Famille : Halogènes (colonne 17)

4°) Kr (Z=36) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁶
  • Électrons de valence : 8 (4s² 4p⁶)
  • Famille : Gaz noble (colonne 18)

Exercice 4.5 : Configurations d'ions

Donner la configuration électronique des ions suivants :

1°) Na⁺ (Z=11)

2°) Cl⁻ (Z=17)

3°) Fe²⁺ (Z=26)

4°) Fe³⁺ (Z=26)

5°) Cu⁺ (Z=29)

6°) Cu²⁺ (Z=29)

💡 Aide de résolution

  • Ion positif (cation) : enlever des électrons
  • Ion négatif (anion) : ajouter des électrons
  • ⚠️ Important : Pour les métaux de transition, on enlève d'abord les électrons 4s AVANT les électrons 3d !

✅ Correction

1°) Na⁺ (Z=11, 10 électrons) :

(1s)²(2s)²(2p)⁶

→ Configuration du Néon (gaz noble)

2°) Cl⁻ (Z=17, 18 électrons) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶

→ Configuration de l'Argon (gaz noble)

3°) Fe²⁺ (Z=26, 24 électrons) :

Atome Fe : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁶(4s)²

On enlève 2 électrons 4s :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁶

4°) Fe³⁺ (Z=26, 23 électrons) :

On enlève 2 électrons 4s + 1 électron 3d :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁵

→ Demi-couche 3d⁵ particulièrement stable !

5°) Cu⁺ (Z=29, 28 électrons) :

Atome Cu : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰(4s)¹

On enlève 1 électron 4s :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰

→ Sous-couche 3d pleine (très stable)

6°) Cu²⁺ (Z=29, 27 électrons) :

On enlève 1 électron 4s + 1 électron 3d :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁹

Exercice 4.6 : États excités

Pour le carbone (Z=6), on considère les configurations suivantes :

A : (1s)²(2s)²(2p)²

B : (1s)²(2s)¹(2p)³

C : (1s)²(2s)²(2p)¹(3s)¹

D : (1s)²(2s)²(2p)³

1°) Laquelle correspond à l'état fondamental ?

2°) Lesquelles correspondent à des états excités ?

3°) Laquelle est impossible ?

💡 Aide de résolution

  • État fondamental : configuration de plus basse énergie (Klechkowski + Hund)
  • État excité : un électron est promu vers un niveau supérieur
  • Impossible : violation de Pauli ou mauvais nombre d'électrons

✅ Correction

1°) État fondamental :

Configuration A : (1s)²(2s)²(2p)²

  • 6 électrons ✓
  • Respecte Klechkowski (remplissage dans l'ordre) ✓
  • Respecte Hund (2 électrons célibataires dans 2p) ✓
  • C'est la configuration de plus basse énergie

2°) États excités :

Configuration B : (1s)²(2s)¹(2p)³

  • 6 électrons ✓
  • Un électron 2s a été promu en 2p → état excité

Configuration C : (1s)²(2s)²(2p)¹(3s)¹

  • 6 électrons ✓
  • Un électron 2p a été promu en 3s → état excité

3°) Configuration impossible :

Configuration D : (1s)²(2s)²(2p)³

  • 7 électrons ❌ (le carbone n'en a que 6 !)
  • Cette configuration est impossible pour le carbone

Exercice 4.7 : Cases quantiques et règle de Hund

Représenter les cases quantiques de la sous-couche 3p pour les configurations suivantes de l'atome de soufre S (Z=16) :

1°) État fondamental : (1s)²(2s)²(2p)⁶(3s)²(3p)⁴

2°) État excité 1 : (1s)²(2s)²(2p)⁶(3s)²(3p)³(4s)¹

3°) État excité 2 : (1s)²(2s)²(2p)⁶(3s)¹(3p)⁵

💡 Aide de résolution

  • La sous-couche 3p a 3 orbitales
  • État fondamental : appliquer la règle de Hund (maximiser les spins parallèles)
  • États excités : vérifier que le nombre total d'électrons reste 16

✅ Correction

1°) État fondamental (3p⁴) :

3p : ↑↓   ↑   ↑
  • 4 électrons dans 3 orbitales
  • 1 doublet + 2 célibataires (spins parallèles)
  • Respecte la règle de Hund ✓

2°) État excité 1 (3p³ 4s¹) :

3p : ↑   ↑   ↑
4s : ↑
  • 3 électrons dans 3p (1 par orbitale, spins parallèles)
  • 1 électron dans 4s
  • Total : 16 électrons ✓
  • Un électron 3p a été promu en 4s → état excité

3°) État excité 2 (3s¹ 3p⁵) :

3s : ↑
3p : ↑↓   ↑↓   ↑
  • 1 électron dans 3s
  • 5 électrons dans 3p (2 doublets + 1 célibataire)
  • Total : 16 électrons ✓
  • Un électron 3s a été promu en 3p → état excité

Exercice 4.8 : Identification à partir de la configuration

Identifier l'élément chimique correspondant à chaque configuration électronique :

1°) (1s)²(2s)²(2p)⁶(3s)²(3p)³

2°) (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁵

3°) (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)⁵

4°) [Ar] 4s² 3d³

💡 Aide de résolution

  • Compter le nombre total d'électrons = Z (pour un atome neutre)
  • Utiliser le tableau périodique pour identifier l'élément
  • [Ar] = configuration de l'Argon (18 électrons)

✅ Correction

1°) (1s)²(2s)²(2p)⁶(3s)²(3p)³

  • Total : 2+2+6+2+3 = 15 électrons
  • Z = 15 → Phosphore (P)

2°) (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁵

  • Total : 2+2+6+2+6+2+10+5 = 35 électrons
  • Z = 35 → Brome (Br)
  • C'est un halogène (colonne 17)

3°) (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)¹(3d)⁵

  • Total : 2+2+6+2+6+1+5 = 24 électrons
  • Z = 24 → Chrome (Cr)
  • C'est une exception à la règle de Klechkowski !

4°) [Ar] 4s² 3d³

  • [Ar] = 18 électrons
  • Total : 18 + 2 + 3 = 23 électrons
  • Z = 23 → Vanadium (V)

Exercice 4.9 : Paramagnétisme et diamagnétisme

Un atome est paramagnétique s'il possède au moins un électron célibataire (attiré par un champ magnétique).

Un atome est diamagnétique si tous ses électrons sont appariés (repoussé par un champ magnétique).

Déterminer si les atomes/ions suivants sont paramagnétiques ou diamagnétiques :

1°) Zn (Z=30)

2°) O (Z=8)

3°) Fe²⁺ (Z=26)

4°) Cu⁺ (Z=29)

💡 Aide de résolution

  • Écrire la configuration électronique
  • Représenter les cases quantiques des sous-couches partiellement remplies
  • Compter les électrons célibataires
  • 0 célibataire → diamagnétique | ≥1 célibataire → paramagnétique

✅ Correction

1°) Zn (Z=30) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰
3d : ↑↓   ↑↓   ↑↓   ↑↓   ↑↓
  • Tous les électrons sont appariés
  • Diamagnétique

2°) O (Z=8) :

(1s)²(2s)²(2p)⁴
2p : ↑↓   ↑   ↑
  • 2 électrons célibataires dans 2p
  • Paramagnétique

3°) Fe²⁺ (Z=26, 24 électrons) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁶
3d : ↑↓   ↑   ↑   ↑   ↑
  • 4 électrons célibataires dans 3d
  • Paramagnétique (fortement)

4°) Cu⁺ (Z=29, 28 électrons) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)¹⁰
3d : ↑↓   ↑↓   ↑↓   ↑↓   ↑↓
  • Tous les électrons sont appariés (3d pleine)
  • Diamagnétique

Exercice 4.10 : Synthèse - Atomes et ions

Pour chaque espèce, donner :

  • La configuration électronique
  • Le nombre d'électrons célibataires
  • Le caractère paramagnétique ou diamagnétique

1°) Mn (Z=25)

2°) Mn²⁺ (Z=25)

3°) Ag (Z=47)

💡 Aide de résolution

  • Mn : suivre Klechkowski normalement
  • Mn²⁺ : enlever 2 électrons 4s

✅ Correction

1°) Mn (Z=25) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁵

  • 5 électrons célibataires (demi-couche 3d pleine)
  • Paramagnétique (très fortement)

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(3d)⁵
3d : ↑   ↑   ↑   ↑   ↑
  • On a enlevé les 2 électrons 4s
  • 5 électrons célibataires (demi-couche 3d pleine, très stable !)
  • Paramagnétique (très fortement)

3°) Ag (Z=47) :
