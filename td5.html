Exercice 5.1 : Zeff pour le fluor F (Z=9)

Configuration du fluor : (1s)²(2s)²(2p)⁵

1°) Calculer σ et Zeff pour un électron 1s.

2°) Calculer σ et Zeff pour un électron 2s.

3°) Calculer σ et Zeff pour un électron 2p.

4°) En déduire les énergies E1s, E2s, E2p.

5°) Conclure sur la levée de dégénérescence.

💡 Aide de résolution

Pour 1s : 1 autre électron 1s → 0,31

Pour 2s/2p : autres e⁻ de (2s,2p) → 0,35 | e⁻ de 1s → 0,85

✅ Correction

1°) Pour un électron 1s :

σ(1s) = 1 × 0,31 = 0,31
Zeff(1s) = 9 - 0,31 = 8,69
E1s = -13,6 × (8,69²/1²) = -1028,8 eV

2°) Pour un électron 2s :

  • 1 autre e⁻ 2s : 1 × 0,35 = 0,35
  • 5 e⁻ 2p : 5 × 0,35 = 1,75
  • 2 e⁻ 1s : 2 × 0,85 = 1,70
σ(2s) = 0,35 + 1,75 + 1,70 = 3,80
Zeff(2s) = 9 - 3,80 = 5,20
E2s = -13,6 × (5,20²/2²) = -91,94 eV

3°) Pour un électron 2p :

  • 4 autres e⁻ 2p : 4 × 0,35 = 1,40
  • 2 e⁻ 2s : 2 × 0,35 = 0,70
  • 2 e⁻ 1s : 2 × 0,85 = 1,70
σ(2p) = 1,40 + 0,70 + 1,70 = 3,80
Zeff(2p) = 9 - 3,80 = 5,20
E2p = -13,6 × (5,20²/2²) = -91,94 eV

4° & 5°) Conclusion :

  • E1s = -1028,8 eV (très profond)
  • E2s = E2p = -91,94 eV
  • Avec les règles de Slater, E(2s) = E(2p) : la dégénérescence entre 2s et 2p n'est pas levée par cette approximation.
  • En réalité (expérience), E(2s) < E(2p), mais Slater ne le prédit pas.

Exercice 5.2 : Zeff pour le fer Fe (Z=26)

Configuration du fer : (1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)⁶

1°) Calculer σ et Zeff pour un électron 4s.

2°) Calculer σ et Zeff pour un électron 3d.

3°) Comparer les énergies et conclure sur l'ordre de remplissage.

💡 Aide de résolution

Pour 4s : 1 autre e⁻ 4s → 0,35 | e⁻ de (3s,3p) → 0,85 | e⁻ des couches ≤ 2 → 1,00

Pour 3d : 5 autres e⁻ 3d → 0,35 | TOUS les autres e⁻ → 1,00

✅ Correction

1°) Pour un électron 4s :

  • 1 autre e⁻ 4s : 1 × 0,35 = 0,35
  • 8 e⁻ (3s, 3p) : 8 × 0,85 = 6,80
  • 10 e⁻ (1s, 2s, 2p) : 10 × 1,00 = 10,00
  • 6 e⁻ 3d : 6 × 1,00 = 6,00 (les 3d sont "internes" par rapport à 4s)
σ(4s) = 0,35 + 6,80 + 10,00 + 6,00 = 23,15
Zeff(4s) = 26 - 23,15 = 2,85
E4s = -13,6 × (2,85²/4²) = -6,88 eV

2°) Pour un électron 3d :

  • 5 autres e⁻ 3d : 5 × 0,35 = 1,75
  • 18 e⁻ des couches ≤ 3 (hors 3d) : 18 × 1,00 = 18,00
  • 2 e⁻ 4s : 0 (couche externe)
σ(3d) = 1,75 + 18,00 = 19,75
Zeff(3d) = 26 - 19,75 = 6,25
E3d = -13,6 × (6,25²/3²) = -59,03 eV

3°) Conclusion :

  • E4s = -6,88 eV (moins négatif, moins stable)
  • E3d = -59,03 eV (plus négatif, plus stable)
  • Attention : ce résultat semble paradoxal car on a vu que 4s se remplit AVANT 3d !
  • En réalité, l'ordre de remplissage dépend de l'énergie totale de l'atome, pas seulement de l'énergie d'une orbitale isolée. L'approximation de Slater montre ses limites ici.

Exercice 5.3 : Énergie d'ionisation du sodium Na (Z=11)

Configuration de Na : (1s)²(2s)²(2p)⁶(3s)¹

1°) Calculer σ et Zeff pour l'électron 3s.

2°) En déduire l'énergie d'ionisation théorique de Na.

3°) Comparer avec la valeur expérimentale (5,14 eV).

💡 Aide de résolution

Pour 3s : 10 e⁻ des couches (n-1)=2 → 0,85 | 2 e⁻ de la couche (n-2)=1 → 1,00

Eion = 0 - E(3s) (passage de 3s à ∞)

✅ Correction

1°) Pour l'électron 3s :

  • 8 e⁻ (2s, 2p) : 8 × 0,85 = 6,80
  • 2 e⁻ (1s) : 2 × 1,00 = 2,00
σ(3s) = 6,80 + 2,00 = 8,80
Zeff(3s) = 11 - 8,80 = 2,20

2°) Énergie d'ionisation :

E3s = -13,6 × (2,20²/3²) = -7,30 eV
Eion = 0 - E3s = 7,30 eV

3°) Comparaison :

  • Valeur théorique (Slater) : 7,30 eV
  • Valeur expérimentale : 5,14 eV
  • Écart : ~42%
  • → Slater surestime l'énergie d'ionisation car il ne prend pas en compte la pénétration de l'orbitale 3s (qui ressent une charge effective plus faible que prévu).

Exercice 5.4 : Tableau périodique - Identification

Identifier l'élément correspondant à chaque description :

1°) Élément de la 3ème période, groupe 16

2°) Métal alcalin de la 4ème période

3°) Halogène de la 3ème période

4°) Gaz noble de la 2ème période

5°) Métal de transition de la 4ème période, groupe 11

💡 Aide de résolution

  • Période = ligne du tableau (couche externe n)
  • Groupe = colonne (configuration de valence)
  • Groupe 1 : ns¹ | Groupe 2 : ns² | Groupe 17 : ns² np⁵ | Groupe 18 : ns² np⁶

✅ Correction

1°) 3ème période, groupe 16 :

  • 3ème période → couche externe n=3
  • Groupe 16 → configuration de valence 3s² 3p⁴
  • Z = 2+2+6+2+4 = 16 → Soufre (S)

2°) Métal alcalin de la 4ème période :

  • 4ème période → couche externe n=4
  • Alcalin → groupe 1 → configuration 4s¹
  • Z = 2+2+6+2+6+1 = 19 → Potassium (K)

3°) Halogène de la 3ème période :

  • 3ème période → n=3
  • Halogène → groupe 17 → 3s² 3p⁵
  • Z = 2+2+6+2+5 = 17 → Chlore (Cl)

4°) Gaz noble de la 2ème période :

  • 2ème période → n=2
  • Gaz noble → groupe 18 → 2s² 2p⁶
  • Z = 2+2+6 = 10 → Néon (Ne)

5°) Métal de transition de la 4ème période, groupe 11 :

  • 4ème période, bloc d
  • Groupe 11 → configuration 3d¹⁰ 4s¹ (exception comme Cu)
  • Z = 2+2+6+2+6+1+10 = 29 → Cuivre (Cu)

Exercice 5.5 : Configuration de valence et famille

Pour chaque élément, donner :

  • La configuration électronique complète
  • La configuration de valence
  • La période et le groupe
  • Le bloc (s, p, d, f)

1°) Calcium Ca (Z=20)

2°) Brome Br (Z=35)

3°) Titane Ti (Z=22)

4°) Cérium Ce (Z=58)

💡 Aide de résolution

  • Suivre l'ordre de Klechkowski
  • La configuration de valence = électrons de la couche externe (n le plus grand)
  • Pour le bloc f, attention aux lanthanides/actinides

✅ Correction

1°) Ca (Z=20) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²
  • Valence : 4s²
  • Période 4, Groupe 2
  • Bloc s (alcalino-terreux)

2°) Br (Z=35) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁵
  • Valence : 4s² 4p⁵
  • Période 4, Groupe 17
  • Bloc p (halogène)

3°) Ti (Z=22) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)²
  • Valence : 4s² 3d²
  • Période 4, Groupe 4
  • Bloc d (métal de transition)

4°) Ce (Z=58) :

(1s)²(2s)²(2p)⁶(3s)²(3p)⁶(4s)²(3d)¹⁰(4p)⁶(5s)²(4d)¹⁰(5p)⁶(6s)²(4f)¹(5d)¹
  • Valence : 6s² 4f¹ 5d¹ (exception)
  • Période 6, Lanthanide
  • Bloc f (terre rare)

Exercice 5.6 : Évolution de Zeff dans une période

Calculer Zeff pour un électron 2p dans les atomes suivants :

1°) Bore B (Z=5) : (1s)²(2s)²(2p)¹

2°) Carbone C (Z=6) : (1s)²(2s)²(2p)²

3°) Azote N (Z=7) : (1s)²(2s)²(2p)³

4°) Oxygène O (Z=8) : (1s)²(2s)²(2p)⁴

5°) Fluor F (Z=9) : (1s)²(2s)²(2p)⁵

6°) Conclure sur l'évolution de Zeff le long d'une période.

💡 Aide de résolution

Pour un électron 2p :

  • Autres e⁻ 2p : (nb-1) × 0,35
  • e⁻ 2s : 2 × 0,35
  • e⁻ 1s : 2 × 0,85

✅ Correction

1°) B (2p¹) :

σ = 0×0,35 + 2×0,35 + 2×0,85 = 0 + 0,70 + 1,70 = 2,40
Zeff = 5 - 2,40 = 2,60

2°) C (2p²) :

σ = 1×0,35 + 2×0,35 + 2×0,85 = 0,35 + 0,70 + 1,70 = 2,75
Zeff = 6 - 2,75 = 3,25

3°) N (2p³) :

σ = 2×0,35 + 2×0,35 + 2×0,85 = 0,70 + 0,70 + 1,70 = 3,10
Zeff = 7 - 3,10 = 3,90

4°) O (2p⁴) :

σ = 3×0,35 + 2×0,35 + 2×0,85 = 1,05 + 0,70 + 1,70 = 3,45
Zeff = 8 - 3,45 = 4,55

5°) F (2p⁵) :

σ = 4×0,35 + 2×0,35 + 2×0,85 = 1,40 + 0,70 + 1,70 = 3,80
Zeff = 9 - 3,80 = 5,20

6°) Conclusion :

ÉlémentZZeff(2p)
B52,60
C63,25
N73,90
O84,55
F95,20

Zeff augmente le long d'une période car Z augmente plus vite que σ. Cela explique pourquoi le rayon atomique diminue le long d'une période (les électrons sont plus fortement attirés par le noyau).
