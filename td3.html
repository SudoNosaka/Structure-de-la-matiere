Exercice 3.1 : Équation de Schrödinger

1°) Écrire l'équation de Schrödinger indépendante du temps pour un état stationnaire.

2°) Que représente la fonction d'onde Ψ ?

3°) Quelle est la signification physique de |Ψ|² ?

4°) Que signifie la condition de normalisation ∫|Ψ|²dτ = 1 ?

💡 Aide de résolution

1°) L'équation fait intervenir l'opérateur hamiltonien Ĥ, la fonction d'onde Ψ et l'énergie E.

2°) Ψ est une fonction mathématique qui décrit l'état quantique du système.

3°) Pense à la densité de probabilité.

4°) L'intégrale est faite sur tout l'espace.

✅ Correction

1°) Équation de Schrödinger :

Ĥ · Ψ = E · Ψ

Où :

  • Ĥ : opérateur hamiltonien (énergie cinétique + énergie potentielle)
  • Ψ : fonction d'onde
  • E : énergie de l'état

2°) La fonction d'onde Ψ :

  • Décrit complètement l'état quantique du système
  • Dépend des coordonnées spatiales (r, θ, φ) en coordonnées sphériques
  • N'a pas de signification physique directe (peut être complexe)

3°) Signification de |Ψ|² :

  • |Ψ(r)|² représente la densité de probabilité de présence de l'électron au point r
  • La probabilité de trouver l'électron dans un volume élémentaire dτ est : dP = |Ψ|² · dτ

4°) Condition de normalisation :

∫ |Ψ|² dτ = 1

Cela signifie que la probabilité de trouver l'électron quelque part dans l'espace est de 100%. L'électron existe forcément quelque part.

Exercice 3.2 : Séparation des variables

Pour l'atome d'hydrogène, la fonction d'onde se sépare en :

Ψn,l,m(r,θ,φ) = Rn,l(r) · Yl,m(θ,φ)

1°) Que représente R(r) ?

2°) Que représente Y(θ,φ) ?

3°) Quels sont les 3 nombres quantiques qui apparaissent et que définissent-ils ?

💡 Aide de résolution

1°) R(r) dépend de la distance au noyau.

2°) Y(θ,φ) dépend de la direction.

3°) Les 3 nombres quantiques caractérisent l'orbitale.

✅ Correction

1°) R(r) : partie radiale de la fonction d'onde

  • Dépend de la distance r au noyau
  • Détermine la taille de l'orbitale
  • Présente des nœuds radiaux (surfaces sphériques où Ψ = 0)

2°) Y(θ,φ) : partie angulaire de la fonction d'onde

  • Dépend des angles θ et φ (direction)
  • Détermine la forme de l'orbitale (sphérique, haltère, trèfle...)
  • Présente des nœuds angulaires (plans ou cônes où Ψ = 0)

3°) Les 3 nombres quantiques :

SymboleNomValeursDéfinit
nPrincipal1, 2, 3...Couche (taille, énergie)
lAzimutal0, 1, ..., n-1Sous-couche (forme)
mMagnétique-l, ..., 0, ..., +lOrientation spatiale

Exercice 3.3 : Nombres quantiques - Valeurs possibles

Pour chaque cas, donner les valeurs possibles du nombre quantique demandé :

1°) n = 3 : quelles sont les valeurs possibles de l ?

2°) l = 2 : quelles sont les valeurs possibles de m ?

3°) n = 4, l = 1 : combien y a-t-il d'orbitales ?

4°) n = 3 : combien y a-t-il d'orbitales au total dans cette couche ?

5°) Quelles sont les valeurs possibles de ms ?

💡 Aide de résolution

Rappels :

  • l va de 0 à n-1
  • m va de -l à +l
  • Nombre d'orbitales dans une sous-couche l = 2l+1
  • Nombre d'orbitales dans une couche n = n²
  • ms = ±½

✅ Correction

1°) Pour n = 3 :

l = 0, 1, 2

(sous-couches 3s, 3p, 3d)

2°) Pour l = 2 :

m = -2, -1, 0, +1, +2

(5 orbitales d)

3°) Pour n = 4, l = 1 (sous-couche 4p) :

Nombre d'orbitales = 2l + 1 = 2(1) + 1 = 3 orbitales

(4px, 4py, 4pz)

4°) Pour n = 3 :

Nombre total d'orbitales = n² = 3² = 9 orbitales

Détail :

  • 3s (l=0) : 1 orbitale
  • 3p (l=1) : 3 orbitales
  • 3d (l=2) : 5 orbitales
  • Total : 1 + 3 + 5 = 9 orbitales

5°) Valeurs de ms :

ms = +½ ou -½

(spin de l'électron)

Exercice 3.4 : Identification d'orbitales

Pour chaque jeu de nombres quantiques, dire si l'orbitale existe et donner son nom :

1°) n = 2, l = 0, m = 0

2°) n = 3, l = 2, m = -1

3°) n = 2, l = 2, m = 0

4°) n = 4, l = 1, m = +2

5°) n = 3, l = 1, m = -1

💡 Aide de résolution

Pour qu'une orbitale existe :

  • n ≥ 1 (entier positif)
  • 0 ≤ l ≤ n-1
  • -l ≤ m ≤ +l

Nomenclature : chiffre_n + lettre (s, p, d, f)

✅ Correction

1°) n = 2, l = 0, m = 0

  • Vérification : l = 0 ≤ n-1 = 1 ✓ | m = 0 (dans [-0, +0]) ✓
  • Existe → Orbitale 2s

2°) n = 3, l = 2, m = -1

  • Vérification : l = 2 ≤ n-1 = 2 ✓ | m = -1 (dans [-2, +2]) ✓
  • Existe → Orbitale 3d (une des 5 orbitales d)

3°) n = 2, l = 2, m = 0

  • Vérification : l = 2 ≤ n-1 = 1 ❌
  • N'existe pas (l ne peut pas être égal à n)

4°) n = 4, l = 1, m = +2

  • Vérification : l = 1 ≤ n-1 = 3 ✓ | m = +2 (dans [-1, +1]) ❌
  • N'existe pas (m ne peut pas être en dehors de [-l, +l])

5°) n = 3, l = 1, m = -1

  • Vérification : l = 1 ≤ n-1 = 2 ✓ | m = -1 (dans [-1, +1]) ✓
  • Existe → Orbitale 3p (une des 3 orbitales p)

Exercice 3.5 : Formes des orbitales

1°) Décrire la forme des orbitales s, p, d.

2°) Combien y a-t-il d'orientations spatiales pour chaque type d'orbitale ?

3°) Qu'est-ce qu'un nœud ? Combien y a-t-il de nœuds pour une orbitale 3s ?

4°) Quelle est la différence entre un nœud radial et un nœud angulaire ?

💡 Aide de résolution

1°) Pense aux formes géométriques (sphère, haltère, trèfle).

2°) Nombre d'orientations = 2l+1

3°) Un nœud est une région où Ψ = 0. Nombre total de nœuds = n-1

4°) Nœuds radiaux : n-l-1 | Nœuds angulaires : l

✅ Correction

1°) Formes des orbitales :

TypeFormeCaractéristiques
s (l=0) Sphère Symétrie sphérique, pas de nœud angulaire
p (l=1) Haltère (2 lobes) 3 orientations : px, py, pz. 1 plan nodal
d (l=2) Trèfle (4 lobes) 5 orientations : dxy, dxz, dyz, dz², dx²-y². 2 plans nodaux

2°) Nombre d'orientations spatiales :

  • Orbitales s : 2(0)+1 = 1 orientation
  • Orbitales p : 2(1)+1 = 3 orientations
  • Orbitales d : 2(2)+1 = 5 orientations

3°) Définition d'un nœud :

Un nœud est une région de l'espace où la fonction d'onde Ψ = 0, donc où la probabilité de trouver l'électron est nulle.

Pour une orbitale 3s (n=3, l=0) :

Nombre total de nœuds = n - 1 = 3 - 1 = 2 nœuds

4°) Différence entre nœuds radiaux et angulaires :

TypeNombreDescriptionExemple 3s
Nœuds radiaux n - l - 1 Surfaces sphériques où Ψ = 0 3 - 0 - 1 = 2 nœuds radiaux
Nœuds angulaires l Plans ou cônes où Ψ = 0 0 nœud angulaire

Exercice 3.6 : Spin et spin-orbitale

1°) Qu'est-ce que le spin d'un électron ?

2°) Quelles sont les valeurs possibles du nombre quantique de spin ms ?

3°) Qu'est-ce qu'une spin-orbitale ?

4°) Combien d'électrons peut contenir une spin-orbitale ? Une orbitale ?

💡 Aide de résolution

1°) Le spin est un moment cinétique intrinsèque.

2°) ms prend 2 valeurs.

3°) Une spin-orbitale inclut les variables d'espace ET de spin.

4°) Pense au principe de Pauli.

✅ Correction

1°) Le spin :

  • Moment cinétique intrinsèque de l'électron
  • Image classique : comme si l'électron "tournait sur lui-même" (mais c'est purement quantique)
  • Caractérisé par le nombre quantique s = ½ (toujours pour l'électron)

2°) Valeurs de ms :

ms = +½ ou -½

On parle souvent de spin "up" (+½) et "down" (-½).

3°) Spin-orbitale :

  • Fonction d'onde qui comprend les variables d'espace ET la variable de spin
  • Caractérisée par 4 nombres quantiques : n, l, m, ms
  • Exemple : (2px, +½) est une spin-orbitale

4°) Capacité :

  • Une spin-orbitale : 1 électron max (caractérisée par 4 nombres quantiques uniques)
  • Une orbitale : 2 électrons max (de spins opposés, selon le principe de Pauli)

Exercice 3.7 : Énergie dans l'atome d'hydrogène

1°) Donner l'expression de l'énergie En d'un électron dans l'atome d'hydrogène en fonction de n.

2°) Calculer l'énergie des niveaux n = 1, 2, 3, 4 (en eV).

3°) L'énergie dépend-elle de l et m pour l'atome d'hydrogène ?

4°) Qu'appelle-t-on "dégénérescence" ?

💡 Aide de résolution

1°) En = -13,6 × Z²/n² eV (pour H, Z = 1)

3°) Pour H, E ne dépend que de n (pas de l ni m).

4°) La dégénérescence est le nombre d'états ayant la même énergie.

✅ Correction

1°) Énergie dans l'atome d'hydrogène :

En = -13,6 × Z²/n² eV = -13,6/n² eV (pour H, Z = 1)

2°) Énergies des niveaux :

E1 = -13,6/1² = -13,6 eV
E2 = -13,6/2² = -3,4 eV
E3 = -13,6/3² = -1,51 eV
E4 = -13,6/4² = -0,85 eV

3°) Pour l'atome d'hydrogène :

  • L'énergie ne dépend que de n
  • Elle ne dépend pas de l ni de m
  • Toutes les orbitales d'une même couche n ont la même énergie

4°) Dégénérescence :

La dégénérescence est le nombre d'états quantiques (orbitales) ayant la même énergie.

Pour l'atome d'hydrogène :

  • Couche n=1 : 1 orbitale (1s) → dégénérescence = 1
  • Couche n=2 : 4 orbitales (2s, 2px, 2py, 2pz) → dégénérescence = 4
  • Couche n=3 : 9 orbitales (3s, 3p×3, 3d×5) → dégénérescence = 9
  • Couche n : dégénérescence = n²

Exercice 3.8 : Atomes polyélectroniques

1°) Pourquoi ne peut-on pas résoudre exactement l'équation de Schrödinger pour un atome à N électrons (N ≥ 2) ?

2°) Quelle approximation fait-on ?

3°) Quelle est la conséquence sur l'énergie des orbitales ?

4°) Pour un atome polyélectronique, l'énergie dépend-elle encore uniquement de n ?

💡 Aide de résolution

1°) Pense à l'interaction entre les électrons.

2°) On utilise les orbitales de H comme base.

3°) La dégénérescence est levée.

4°) L'énergie dépend maintenant de n ET l.

✅ Correction

1°) Problème de la résolution exacte :

Pour un atome à N électrons (N ≥ 2), l'hamiltonien contient un terme de répulsion électron-électron :

Ĥ = Σ Eci + Σ VN-ei + Σi<j Vei-ej

Ce terme de répulsion entre électrons rend la séparation des variables impossible → résolution exacte impossible.

2°) Approximation :

  • On utilise les orbitales de l'atome d'hydrogène comme base
  • On considère que chaque électron se déplace dans un potentiel moyen créé par le noyau et les autres électrons
  • Les orbitales obtenues sont semblables à celles de H, mais avec des énergies différentes

3°) Conséquence sur l'énergie :

  • La dégénérescence est levée
  • L'énergie dépend maintenant de n ET de l
  • 2 sous-couches différentes n'auront pas la même énergie
  • Exemple : E(2s) ≠ E(2p) pour un atome polyélectronique

4°) Pour un atome polyélectronique :

  • L'énergie dépend de n ET de l (pas seulement de n)
  • À l'intérieur d'une même couche n, les sous-couches ont des énergies différentes
  • Ordre d'énergie croissante : ns < np < nd < nf
  • C'est pour ça que 4s se remplit AVANT 3d (car E(4s) < E(3d))

Exercice 3.9 : Nombre d'orbitales et d'électrons

Compléter le tableau suivant :

Couche n Sous-couches Nb d'orbitales Nb max d'électrons
1 (K)???
2 (L)???
3 (M)???
4 (N)???

💡 Aide de résolution

Rappels :

  • Sous-couches de la couche n : l = 0, 1, ..., n-1
  • Nb d'orbitales dans sous-couche l = 2l+1
  • Nb d'orbitales dans couche n = n²
  • Nb max d'électrons dans couche n = 2n²

✅ Correction

Couche n Sous-couches Nb d'orbitales Nb max d'électrons
1 (K) 1s 1² = 1 2(1²) = 2
2 (L) 2s, 2p 2² = 4 2(2²) = 8
3 (M) 3s, 3p, 3d 3² = 9 2(3²) = 18
4 (N) 4s, 4p, 4d, 4f 4² = 16 2(4²) = 32

Détail pour n=2 :

  • 2s (l=0) : 1 orbitale
  • 2p (l=1) : 3 orbitales
  • Total : 1 + 3 = 4 orbitales
  • Électrons max : 4 × 2 = 8 électrons

Détail pour n=3 :

  • 3s (l=0) : 1 orbitale
  • 3p (l=1) : 3 orbitales
  • 3d (l=2) : 5 orbitales
  • Total : 1 + 3 + 5 = 9 orbitales
  • Électrons max : 9 × 2 = 18 électrons
